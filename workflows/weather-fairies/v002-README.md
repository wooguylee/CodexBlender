# 오늘의 날씨 요정들 v002 — 눈송이·바람 추가

2026-10-06 (한국 시간). 사용자 요청: **“눈송이와 바람 케릭터도 필요해.”**
기존 몽실·해롱·또르의 디자인을 유지하고 송송·솔솔을 추가한 5인조 정지 시안이다.

| 이름 | 설정 | 디자인 |
|---|---|---|
| 송송 / SONGSONG | 장난꾸러기 눈송이 | 둥근 육각 얼굴, 6개 결정 축과 12개 가지, 윙크, 보라 장갑과 신발 |
| 솔솔 / SOLSOL | 산들바람 | 민트색 몸과 이어지는 소용돌이, 오므린 입, 살구색 스카프, 한 발을 든 포즈 |

## 원본과 결과

- Scene `Weather_Fairies_v002`, 카메라 `WF2_Camera`, 독립 원본 `scenes/weather-fairies-v002.blend`.
- 모든 결과는 `outputs/weather-fairies/v002/`에 보관한다.
- `weather-fairies-five.png`, `weather-fairies-five-clean.png`: 5명 단체, 각각 3200×1600.
- `snow-and-wind.png`: 신규 2명, 2160×1440.
- `songsong.png`, `solsol.png`: 개별 이미지, 각각 1080×1080.
- Cycles OptiX 96 samples, AgX. 외부 이미지·폰트·모델·애드온·다운로드 없음.
- 캐릭터별 컬렉션과 Root Empty로 분리한 실제 3D 메시/곡선이다. 뼈대 리깅과 애니메이션은 아직 없다.

## 실행 순서

1. 브리찌 `status`와 `scene`으로 v001 원본이 활성화됐는지 확인한다.
2. `05_add_snow_and_wind.py`: v001의 객체·데이터·재질을 독립 복제하고 v002 신규 캐릭터를 만든다.
3. 실제 미리보기 확인 후 `06_finish_five_friends.py`: 솔솔 몸/머리/소용돌이를 융합하고 송송 대비를 보정한다. 최종 이미지 5장과 단일 Scene 원본을 출력한다.
4. 독립 Blender에서 `07_verify_five_source.py`: 화면 경계, 5개 캐릭터, 눈 결정 구성, 바람 융합 메시, 외부 의존성, 실제 재렌더를 검사한다.
5. 일반 Python/Pillow에서 `08_check_five_outputs.py`: PNG 무결성·크기·알파, 독립 재렌더 차이, 기존 파일 SHA-256과 브리찌 성공 결과를 검사한다.

05/06의 생성 작업을 이미 완성된 장면에서 반복 실행하지 않는다. 후속 변경은 `WF2_` 객체에 한정하고 새 버전으로 보관한다.
브리찌는 변경 전 백업과 실행 코드, 변경 후 원본, 카메라 미리보기를 작업별로 저장한다.
