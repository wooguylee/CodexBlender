- 독립 원본: `scenes/weather-fairies-v001.blend`.

- 개별 이미지: `mongsil.png`, `haerong.png`, `ttorr.png`, 각각 1080×1080.

- 3개 전용 캐릭터 컬렉션과 Root Empty로 분리했다. **정지 시안이며 뼈대 리깅·애니메이션은 아직 없다.**

## 실행과 후속 수정

1. 브리찌 `status`와 `scene`을 확인한다.
2. 새 장면이 없는 원본에서 `01_build_characters.py`를 브리찌 `run`으로 실행한다.
3. 첫 카메라 렌더를 직접 검토한다. `02_polish_and_render.py`는 옅은 색과 놀란 듯한 입을 보정하고 단체·개별 이미지를 렌더한다.
4. `03_verify_standalone.py`를 독립 Blender에서 실행하여 단일 Scene 원본과 외부 의존성, 화면 경계, 실제 재렌더를 검사한다.
5. `04_check_outputs.py`로 PNG 무결성, 재렌더 픽셀 일치, 기존 원본 해시를 확인한다.

이미 완성된 장면에서 01/02를 그대로 재실행하지 않는다. 가드가 기존 Scene/파일을 보호한다.
후속 수정은 실제 이름을 확인한 뒤 `WF1_` 객체를 대상으로 별도 스크립트를 만들고 결과 버전을 올린다.
개별 렌더를 위해 임시로 숨긴 캐릭터/전시대/글자는 02 종료 시 모두 복원한다.
