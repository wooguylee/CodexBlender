# 날씨 요정 5편 제작 계획

> 승인 근거: 사용자가 제시된 5개 시나리오에 대해 “5개 모두 만들어봐”라고 요청했다.
> 실행: superpowers:executing-plans 방식으로 이 대화에서 순차 실행한다. 이미 승인된 제작 범위는 반복 승인 없이 수행한다.

**Goal:** 기존 5개 캐릭터를 이용한 독립된 코미디 영상 5편을 실제 제작·검증·납품한다.
**Architecture:** 브리찌로 별도 제작 Scene을 만들고 캐릭터별 루트/관절/표정 컨트롤과 소품을 구성한다. 편별 애니메이션을 Blender 키프레임으로 굽고 독립 .blend를 저장한다. 실제 기하 렌더를 PNG로 출력하여 FFmpeg로 편집·자막·직접 생성한 오디오와 결합한다.
**Tech Stack:** Blender 5.2 bpy, 브리찌, Python/Pillow/NumPy, FFmpeg.
**Spec:** 아래에 기록한 사용자 승인 시나리오 5개.

## 전역 제약

- 기존 v001/v002 및 다른 장면·결과 보존. 전용 `WS_` Scene과 `outputs/weather-shorts/v001/` 사용.
- 다운로드/추가 설치/네트워크 서버/외부 서비스/유료 자산 없이 제작한다.
- 16:9, 24fps, 대사 없음. 1920×1080 / EEVEE 16 samples로 실제 성능·시각 시험을 거쳐 확정했다.
- 캐릭터 표정, 손발, 몸 기울기, 소품, 컷 전환이 사건과 연결되어야 한다. 정지 이미지 슬라이드쇼로 대체하지 않는다.
- 각 편에 도입·사건·반전·마무리가 있어야 하며 다섯 캐릭터 모두 등장한다.
- 한 편의 렌더 실패나 타임아웃을 전체 성공으로 보고하지 않는다. 완료/진행/대기를 구분한다.
- 원본과 소스·스토리·최종 영상·검증 기록은 프로젝트에 남기고 관련 파일만 커밋·푸시한다.

## 에피소드와 타이밍

1. **단체사진 대소동 / 24초**: 0–5초 모이기, 5–10초 각자 포즈/졸기/숨기, 10–16초 바람에 휘청이며 뒤엉킴, 16초 카메라 플래시, 17–24초 엉뚱한 사진과 모두의 즐거운 반응.
2. **몽실의 별 쿠션을 잡아라 / 30초**: 0–5초 낮잠/재채기, 5–12초 날아간 별과 해롱의 점프, 12–21초 얼음길/또르의 미끄럼 추격, 21–26초 별이 몽실에게 귀환, 26–30초 모두 지쳤지만 몽실은 계속 잠.
3. **꽃 한 송이 키우기 / 32초**: 0–5초 새싹 발견, 5–10초 지나친 햇살, 10–15초 너무 많은 비, 15–20초 결빙, 20–26초 협력과 개화, 26–32초 꽃 재채기/노란 꽃가루 반전.
4. **오늘의 날씨는 누구? / 28초**: 0–6초 햇살 방송, 6–12초 비 등장, 12–18초 눈 등장, 18–23초 바람과 화면 쟁탈, 23–28초 몽실이 화면을 채우고 ‘오늘은 낮잠 자기 좋은 날’.
5. **절대 터뜨리면 안 돼! / 26초**: 0–5초 거품 등장, 5–17초 바람·눈·햇살의 조심스러운 반응, 17–21초 몽실이 다가와 껴안아 터짐, 21–26초 작은 거품 모자 다섯 개와 웃음.

## 작업 순서와 검증

- [x] 제작 Scene/컨트롤/소품 공통 기반 구성; 기존 장면 signature와 원본 SHA-256 기록.
- [x] 대표 프레임과 짧은 실제 움직임 렌더로 재질·얼굴 가시성·접지·속도 확인, 출력 설정 확정.
- [x] 5편 애니메이션 키프레임 제작, 사건 시점별 접촉 시트 확인, 독립 .blend 재개방 검증.
- [x] 각 편 전체 프레임 실제 렌더, 재시작 시 이미 있는 정상 프레임은 보존하고 누락분부터 진행.
- [x] 한국어 제목/필요한 반전 자막과 직접 합성한 배경음/효과음 추가, H.264/AAC MP4 생성.
- [x] 해상도/프레임 수/재생시간/전체 디코딩/오디오 피크/프레임 무결성 검사.
- [x] 편별 사건 대표 장면과 인접 프레임 변화, 고정 배경의 국소 안정성, 급격한 이동·화면 밖 잘림 검사.
- [x] 사용자에게 5편 모두 링크와 미리보기 제공, 현재 상태 기록, 관련 변경 커밋·푸시 및 원격 해시 비교.

## 검토 초점

1. 기존 캐릭터가 바뀌지 않고 다섯 명의 성격이 구분되는가.
2. 쿠션/얼음길/꽃/날씨/거품의 실제 움직임이 이야기와 일치하는가.
3. 숨김·스케일 전환이나 컷에서 의도하지 않은 순간 이동/소품 잔상이 생기지 않는가.
4. 카메라/프레임 여백과 자막이 얼굴이나 중요한 동작을 가리지 않는가.
5. 고정 조명/배경의 깜빡임, 오디오 clipping, 영상 누락을 완료 전에 실제 출력에서 확인했는가.
