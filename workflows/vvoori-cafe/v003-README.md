## 새 이미지와 3D 역할

공원과 실내는 내장 **image_gen**으로 이번 구도에 맞춰 새로 생성했다.
Blender가 먼저 만든 단색 가이드는 이미지 생성의 원근 참고일 뿐, 최종 배경 자산으로 쓰지 않는다.

- `assets/vvoori-cafe/v003/ai-oblique-park.png`: 가을 공원과 사선 도로, RGB 1672×941.
- `assets/vvoori-cafe/v003/ai-oblique-interior.png`: 천장·벽·바닥·우측 의자와 화분, 투명 창 개구부, RGBA 1672×941.
- [전체 생성 프롬프트](v003-image-prompts.md), 자산 메타데이터 `assets/vvoori-cafe/v003/provenance.json`.
- 생성 PNG를 원본 그대로 보존하고 `.blend`에 pack했다. 원본 파일과 packed 바이트의 SHA-256이 일치한다.

Blender 실제 기하는 창틀/창턱, 테이블/받침, 커피잔/손잡이/커피/받침접시, 책,
차량 6대와 낙엽 56개다. 재질은 고정 방향 명암을 두 단계로 나누어 만화 배경과 맞춘다.
자동차의 그림자도 선명한 셀 형태로 처리하여 투명 표면의 렌더 노이즈를 줄였다.
차량의 실제 3D 경로는 생성된 도로의 두 차선에 카메라 역투영으로 맞췄다.
멀리 이동하는 차량은 120–240m 구간에서 서서히 작아진 뒤 0 크기가 된 상태로 순환한다.
낙엽도 지면 근처에서 작아져 반복 시 갑자기 재등장하지 않는다.

합성 순서는 `생성 공원 → 움직이는 3D 차량/낙엽 → 생성 실내 → 실제 3D 창틀/가구`다.
고정 카메라에서 실내 깜빡임을 방지하기 위해 **창틀/가구의 3D 렌더를 한 번 캐시**한다.
그 기하는 삭제하지 않고 원본에 유지하며, 움직이는 3D만 매 프레임 다시 렌더한다.
이미지는 sRGB / Standard / 노출 0으로 처리하고, 실내 알파는 합성 노드에서만 정규화한다.

## 원본 편집과 재현

다른 PC에서는 `scripts/blender.ps1 start --file scenes/vvoori-cafe-v003.blend`로 연다.
세 장의 합성 이미지가 pack되어 있어 이 `.blend`만으로도 결과를 렌더할 수 있다.
생성 PNG와 제작 코드는 Git에도 별도로 보관한다. 최종 MP4·포스터·레이어 확인표·재생 페이지는 이번 완성 결과로 Git에 명시적으로 포함하고,
480장 렌더 프레임과 작업 중간 파일은 로컬 `outputs/`에 보관한다.

- `VC3_EditAll3D`: 기본 편집 뷰. 창틀/가구/차량/낙엽을 실제 3D로 확인한다.
- `VC3_Motion`: 실제 출력용 뷰 레이어. 차량/낙엽만 렌더하고 정적 레이어와 합성한다.
- `VC3_Guides`: 생성 참고용 단색 가이드. 최종 렌더에서 제외한다.
- 창틀/가구/카메라를 수정하면 `VC3_WindowSet` + `VC3_Foreground`를 다시 RGBA로 렌더하여 `Static3D` 합성 노드의 packed 이미지를 갱신해야 한다.
- 카메라 변경 시 생성 이미지도 그 투시에 맞춰 다시 생성/정합한다. 현재 구성은 고정 카메라용이다.

처음부터 만드는 순서는 11번 구도 → 이미지 생성 → 12번 합성 → 13번 차선/가구 정합 → 14번 전체 렌더 →
15번 MP4/검증 → 새 Blender 프로세스에서 16번 일반 원본 저장 → 17번 재개방 렌더 → 18번 편집 화면 표시다.
11/12/13/14번은 새 v003 제작용이며 완성 Scene이나 기존 프레임 위에서 무조건 재실행하지 않는다.
수정은 새 버전 또는 명시적 변경 스크립트로 수행한다. 기존 autumn-cafe/v001/v002 원본은 보존했다.

## 검증

- 실제 PNG 480장 전체 무결성 확인. 천장/벽/바닥/창틀/테이블/책/컵/받침/조명 10개 정적 영역은 모든 프레임에서 채널 차이 **0**.
- MP4 전체 디코딩 정상. 시작/끝 프레임 픽셀 동일. 별도 렌더한 480번째 프레임도 첫 프레임과 차이 0.
- MP4 압축 후 정적 영역의 프레임 간 평균 차이는 최대 0.255 미만(8비트 채널 기준).
- 62개 애니메이션 시작/끝 변환 오차 0. 자동차 반복 시점은 뒤쪽 카메라 밖 또는 크기 0 상태다.
- 전용 원본을 독립 Blender 프로세스에서 정상 저장 후 다시 열어 실제 Full HD 렌더 완료.
- 독립 프로세스 재렌더와 최초 PNG의 전체 평균 차이 0.0215 미만, 비교한 실내 정적 영역 차이 0.
  재렌더의 움직이는 3D 경계에는 샘플링 차이가 있으므로 독립 재렌더가 바이트 동일하다고 주장하지 않는다.
- 이전 autumn-cafe/v001/v002 원본 SHA-256 유지.
- 실제 결과: [영상 검증](v003-verification-summary.json), [독립 원본 검증](v003-source-verification.json).

Windows / Blender 5.2.1 LTS / RTX 3090 OptiX에서 검증했다. 원본 이미지는 1672×941이며 Full HD 합성 시 확대된다.
11번의 각도 비교 허용 오차와 14번의 원거리 순환 판정을 실제 Blender/투시 결과에 맞춰 조정했다.
11b는 최초 가이드 생성 중단 후의 복구 이력으로, 수정된 11번의 정상 재현에는 필요 없다.

이번 작업은 Blender 합성·렌더로 완료했으며 Resolve 변경은 없다.
