# vvoori-cafe v005 — 프레임도 이미지로 처리한 넓은 통창

2026-10-02. 사용자 요청: 창 프레임을 Blender로 만들지 않고, 필요하면 카페 이미지에 포함하며 통창에 맞춘다.

## 반영 내용

실내 RGBA를 내장 image_gen으로 다시 편집했다. 창 안쪽의 세로 기둥·격자 없이 공원이 넓게 보이고,
상단/하단/우측 바깥 테두리만 그림에 포함한다. 우측 위에는 유리임을 암시하는 작은 빛 반사 선이 있다.
테이블 두 개·의자 네 개·커피잔·책과 기존 실내 구도는 유지했다.

- 생성 실내: `assets/vvoori-cafe/v005/ai-panoramic-interior.png`, RGBA 1672×941.
- 편집 입력은 v004 실내이며, [실제 프롬프트](v005-image-prompt.md)를 기록했다.
- 공원은 기존 `assets/vvoori-cafe/v003/ai-oblique-park.png`를 재사용한다.
- **3D 창틀·창턱·가구가 새 Scene에 없으며, 이전 창틀 렌더 캐시도 합성 노드에서 제거했다.**
- Blender가 매 프레임 렌더하는 기하는 차량 6대와 낙엽 56개다. 카메라의 50도 사선 구성과 셀 명암은 유지한다.

합성은 `공원 PNG → 차량/낙엽 3D → 통창/테두리/가구를 포함한 실내 RGBA`의 세 단계다.
실내는 직접 생성한 그림이며 Blender 렌더를 이미지로 바꿔 넣은 것이 아니다.
이미지의 투명 창 영역을 통해 외부가 보인다. 생성 alpha는 기존과 같이 합성 노드에서만 정규화한다.

v004 원본과 영상은 보존한다. 새 생성 이미지·원본·최종 영상·포스터·재생 페이지와 코드는 Git에 포함하고,
480장 프레임·중간 백업은 로컬 보관한다.

## 제작과 검증

v004 Scene을 포함한 브리찌에서 24번 적용 → 25번 전체 렌더 → 일반 Python 26번 MP4/검증 →
독립 Blender 27번 정상 원본 저장 → 다시 열어 28번 렌더 검증 순서로 제작한다.
이미 생성된 v005 Scene이나 프레임 위에서 생성 코드를 무조건 재실행하지 않는다.

12개 실내 고정 영역을 480장 전체에서 비교해 원본 PNG의 채널 변화 0을 확인했다.
MP4 전체 디코딩 정상, 시작/끝 픽셀 동일, 별도 렌더한 끝점 차이 0, 정확히 20초다.
압축 후 실내 영역의 평균 변화는 8비트 채널 기준 최대 0.182 미만이다.
독립 원본의 3D 창틀/가구 부재, 이미지 두 장의 packed SHA-256, 62개 애니메이션 끝점 오차 0,
v004 원본/영상 해시 유지와 별도 프로세스에서의 재개방 렌더를 확인했다.
실측 보고서는 `v005-verification-summary.json`, `v005-source-verification.json`이다.

원본은 고정 카메라에 맞춘 합성이다. 창/테두리/가구 변경은 실내 이미지에서 처리하고,
카메라 구도를 바꾸면 두 이미지와 움직임의 투시 정합도 함께 갱신한다.
검증 환경: Windows / Blender 5.2.1 / RTX 3090 OptiX.
